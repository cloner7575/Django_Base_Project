A reusable Django base.

Settings, custom user, templates, and Cursor skills are already here. Add a domain app under apps/ and keep this layout so every new project stays consistent.

Create an app

  1. .venv/bin/python manage.py startapp shop apps/shop
  2. Set name = "apps.shop" and a short label in apps.py
  3. Add the AppConfig to INSTALLED_APPS

Models

Subclass apps.common.models.TimeStampedModel. Put domain rules on the model, not in the view.

UI

Extend templates/base.html. Use tokens in static/css/tokens.css. Follow the ui-ux skill for a11y, forms, and empty states.
